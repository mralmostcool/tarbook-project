# Program Bounded Context Module

The Program Bounded Context manages STCW syllabus curricula, task definitions, syllabus versioning, and the STCW eligibility engine.

## Managed Domain Entities

- [[database/tables/training_programs|training_programs]]: Base STCW training curricula and organization overlays.
- [[database/tables/task_definitions|task_definitions]]: Standardized STCW competency task definitions.
- [[database/tables/tar_books|tar_books]]: Issued TAR Book instances assigned to candidates.
- [[database/tables/eligibility_assessments|eligibility_assessments]]: Automated STCW sea-time dossier records.
