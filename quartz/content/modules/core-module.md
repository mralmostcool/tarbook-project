# Core Bounded Context Module

The Core Bounded Context manages system identity, organizations, candidate profiles, and vessel crew assignments.

## Managed Domain Entities

- [[database/tables/organizations|organizations]]: Maritime Training Institutes (MTI), Shipping Companies, Flag Administrations.
- [[database/tables/app_users|app_users]]: Master user directory, credentials, and global system roles.
- [[database/tables/candidates|candidates]]: Seafarer training profiles with INDOS & CDC numbers.
- [[database/tables/vessel_crew_assignments|vessel_crew_assignments]]: Officer and cadet shipboard roster deployments.
